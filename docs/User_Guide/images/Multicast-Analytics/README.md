Place the Multicast Analytics screenshots in this directory using these exact names:

| File | Capture |
|---|---|

The corresponding insertion points are marked with `<!-- Screenshot: ... -->` comments in `../../User_Guide.md`. After adding each image, replace its comment with Markdown in this form:

```markdown
![Concise description](images/Multicast-Analytics/file-name.png)
```

Crop screenshots to the application window, avoid real credentials or production addresses, and keep text legible at the width used by GitHub's Markdown viewer.
